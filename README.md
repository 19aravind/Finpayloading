# 💳 Finpay - Payment & Savings Platform

Welcome to **Finpay**, a modern payment and savings platform UI design built for practice and showcasing frontend skills.  
This project features a clean, responsive design with a focus on financial services.

## 🚀 Features

- Responsive, mobile-friendly layout
- Hero section with call-to-action
- Pricing plans and product features
- Stats and achievements section
- Smooth, minimal animations
- Reusable UI components
- Professional and clean design

## 🛠 Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Styling:** Tailwind CSS
- **Icons:** Heroicons / Lucide / Font Awesome (update based on what you used)
- **Deployment:** GitHub Pages / Vercel / Netlify (update based on where you hosted)
